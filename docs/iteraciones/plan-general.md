# Plan general de iteraciones

**Supuesto:** Simulación académica comprimida. Cada iteración se documenta como si durara 2 semanas.

| Iteración | Objetivo de aprendizaje | Producto esperado | Esfuerzo estimado | Duración | Hito |
| :--- | :--- | :--- | :---: | :---: | :--- |
| **I1** | Validar si el flujo básico de reserva es comprensible | Prototipo navegable de reserva de turno | 20 h | 2 semanas | Prototipo de reserva validado |
| **I2** | Validar reprogramación y cancelación (evento de cambio) | Prototipo con reprogramación/cancelación simplificada | 22 h | 2 semanas | Reprogramación/cancelación validada |
| **I3** | Validar panel administrativo y privacidad de datos | Prototipo con vista admin y control de privacidad | 26 h | 2 semanas | Panel admin y privacidad validados |
| **I4** | Validar integración simulada, rendimiento y fiabilidad | Versión candidata con integración clínica simulada | 28 h | 2 semanas | Versión final e integración simulada |
| **Total** | | | **96 h** | **8 semanas** | **Demo final y entrega de producto** |

---

**Técnica de estimación:** Tres puntos (PERT) + juicio experto. Cada estimación registra: técnica, entradas, cálculo, rango y responsable de validación.
